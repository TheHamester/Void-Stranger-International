# Void Stranger Russian Localization Guidelines

This file documents the basic guidelines and open questions to ensure consistency, integrity and coherence of the localized text.


# Miscellaneous Guidelines

* Don't use the letter 'ё' - I found it pretty difficult to keep the usage of this letter consistently. It's optional anyway, so I ended up reverting them all back to 'е'. 
* Void Lords should generally speak to the Player and the other souls with polite "Вы", and refer to each other with "Ты". However, Bee may probably switch it around sometimes, and use "Ты" when referring to the Player or other subjects when appropriate - she's just sassy like that.
* Make sure that within the context of nearby lines of text, conjugations, cases, and genders remain consistent.
* Puzzle related stuff should be localized (or not localized) in a way that makes them still solvable in Russian.
* Colors of the rainbow, the word "бог", and referenced brands (e.g. PrimaDonnas) must be censored with asterisks, just like in the main game. If something is censored in the English script, doesn't necessarily means it must be censored in the Russian Localization as well: for example the fruit Orange is not censored in the official Finnish translation, because it doesn't also refer to a color.
* Make sure the translated text fits on the screen, where the text doesn't wrap around, and adjust the localization if neccesary (each letter is 7 pixels on average with 1 pixel spaces, and the screen is 224 pixels wide, use that as a guide). This doesn't apply to dialogue boxes, mostly to UI.

# Open Questions

1. Should the mural inscriptions be translated (e.g. ONLYAMEMORYREMAINS)? since doing so might make the Tail's Brand harder to solve, and render the alphabet at the end of the void completely useless; but at the same time, it might confuse the Players why this specific text is not localized.
2. How should we maximize gender neutrality when referring to the player and/or Void Lords. If using a gendered version of a word is inevitable, should we use the gender based on the way they present themselves? (Add/Bee/Gor/Cif would be more feminine, Eus/Mon/Tan/Lev would probably be more masculine) They will still refer to each other as sisters, no matter the situation, which might just be the way to keep it ambiguous for some Void Lords, but otherwise, Moreover the word Lord itself is pretty masculine, so we can use the word "Властелин" to confuse their gender even more(?)
